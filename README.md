# SoDa Open Research Teaching Datasets (SORTD)
Versioned, reusable datasets for teaching research methods, data analysis, and AI-assisted research workflows.

## Licensing
The datasets in `data/` are released under CC0 1.0 Universal. Source code in `scripts/` is released under the MIT License. Currently, all the datasets are derived from [OpenAlex](https://openalex.org), whose data are released under CC0.
